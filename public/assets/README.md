## Quy tắc sử dụng

- **Badges**: Các badge, nhãn hiệu, xác thực
- **Benefits**: Ảnh minh họa lợi ích sản phẩm
- **Icons**: Icon và biểu tượng nhỏ
- **Logos**: Logo công ty và đối tác
- **Misc**: File không thuộc các danh mục trên
- **Product-images**: Ảnh sản phẩm chính
- **Symptoms**: Ảnh minh họa triệu chứng
- **Testimonials**: Ảnh khách hàng và review

## Lưu ý

- Tất cả đường dẫn trong code đã được cập nhật để phù hợp với cấu trúc mới
- Khi thêm file mới, hãy đặt vào đúng thư mục tương ứng
- Giữ tên file rõ ràng và mô tả
